# Changelog

## 1.0 — first public version

- Twelve OPL2-style FM percussion engines on one added machine: KIK, TOM, BNG, CNG, DJB, TAI, TIM, MAR, BLK, GNG,
  BUB and ZAP.
- SHAPE names the engine; COLOR is the FM depth; SWEEP steps the modulator ratio; CONTOUR shapes the model.
- PUNCH turns the chip's LFO on; GATE holds the note for its length.
- Packaged for the cycles-engines flasher at slot 8 (OS machine 7).
